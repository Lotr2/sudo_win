# Phase 3 · Step 1: Product plan: Design Brief Guide for Freelance Designers

A quick, easy‑to‑follow guide that helps freelance designers set clear expectations with clients before starting work. It includes a ready‑to‑use design brief template and step‑by‑step instructions to save time and reduce misunderstandings.

**What it is:** a written guide (an e-book or PDF)

## Features

- Clear, concise steps to create a professional design brief
- A ready‑to‑use template that you can copy and paste
- Tips for communicating expectations and deliverables
- Checklist to avoid common client misunderstandings
- Time‑saving structure that fits into a busy freelance schedule
