# Phase 3 · Step 1: Product plan: Rate Negotiation Guide for Freelance Designers

A step‑by‑step PDF that shows designers how to set and raise rates with confidence, including scripts and email templates.

**What it is:** a written guide (an e-book or PDF)

## Features

- Clear framework for setting your own rates
- Proven scripts to handle client objections
- Anchoring techniques that justify higher fees
- Sample email templates for outreach
- Quick reference cheat sheet for on‑the‑go use
