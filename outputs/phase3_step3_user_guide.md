# Design Brief Guide for Freelance Designers

## What It Is
A quick, easy‑to‑follow manual that helps you create a professional design brief. It gives you a ready‑to‑copy template, step‑by‑step instructions, and checklists so you can set clear expectations with clients before you start drawing.

## How to Start
1. **Open the guide** and read the *Getting Started* section.
2. **Copy the template** into a new document or a shared folder.
3. **Fill in the client details** (brand guide, decision makers, etc.).
4. **Send the draft brief** to the client for review.

## Using Each Part
### 1. Getting Started
Collect the basics: brand guide, project brief, decision makers, a quick intro call, and a shared folder. A checklist keeps you from missing any item.

### 2. Defining the Project Scope
Write short project goals, list deliverables, set success criteria, note exclusions, and record any assumptions. Use the provided template snippet to keep the format consistent.

### 3. Establishing Timelines and Milestones
Set a kickoff date, define milestones (concept sketches, first draft, reviews, final delivery), and add buffer days. A simple table shows due dates and owners.

### 4. Clarifying Budget and Payment Terms
Document the total cost, payment schedule, and any extra fees. This section is not included in the current guide but should be added to the brief template.

### 5. Review and Approval Process
Outline how feedback loops work and when the client signs off. Include review windows and final delivery dates.

## Limits
- The guide is a *tool*, not a legal contract.
- It covers only the design brief; it does not replace a full project agreement.
- The template is a starting point; adapt it to fit your workflow.

---

## Quick Tips
- Keep a running list of questions in a spreadsheet.
- Use shared calendars or project boards to track milestones.
- Review the brief with the client before any design work begins.
